# VIDEO PROMPTS — QuietForge ZZP Packs | Commander + Octopus

## Unified Brand Identity for ALL videos:

**Character - Owner / Commander:**
- Polish male, 30-34 years old, founder of QuietForge, name Norbert Wozniak
- Look: short beard / stubble, confident, calm commander, not salesman. Athletic / working-class respect, not corporate.
- Outfit: dark charcoal or black tech t-shirt with small amber QuietForge octopus logo left chest, or dark tactical overshirt. No suit.
- Attitude: speaks directly, like leader briefing team. Slight smile, hands gesturing precise.
- Voice tone (PL): bezpośredni, pewny, bez bullshitu, "mówię jak jest, bo sam jestem ZZP mindset"
- Voice tone (NL): direct, no-nonsense, betrouwbaar, "Rotterdamse mentaliteit - niet lullen maar poetsen"

**Octopus Logo - QuietForge Symbol:**
- Not cute cartoon. Tech organism, semi-transparent, dark with amber glowing circuits / nodes on tentacles.
- 8 tentacles extend into digital network (Matrix-like lines), each tentacle working on different social element: one sorts photos, one writes text, one optimizes keywords, one manages calendar, one replies to reviews.
- It works in background behind commander, like living AI organism managing network.
- Colors: dark body #0e0c0a, amber glow #e8a33d, subtle green checkmarks where work done.

**Environments:**
- Dark terminal office / command center. Multiple monitors with code / dashboards / analytics but blurred shallow DOF.
- Amber rim light, soft key.
- No bright white corporate office.
- Feels like developer-tool meets real workshop.

**Technical Spec for all videos:**
- 8 seconds ideal for Reels / TikTok / Shorts
- 9:16 vertical primary, also 16:9 horizontal for landing page
- 4K, cinematic, realistic, not AI-slop
- Subtitles burned-in PL/NL (white with amber keywords)
- End card: quietforge.flexgrafik.nl | logo
